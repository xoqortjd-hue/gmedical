# 영업팀 UI 개선 프로젝트 - 요구사항 및 구현 계획

> **작성일**: 2026-01-05  
> **버전**: 1.0  
> **상태**: 검토 대기

---

## 1. 프로젝트 개요

### 1.1 목표
모바일 앱에 **팀 선택 화면**을 추가하고, **영업팀 전용 UI**를 개발하여 입출고 업무의 사용자 편의성을 향상시킵니다.

### 1.2 핵심 원칙
- **동일 DB 공유**: 영업팀과 관리팀은 같은 데이터베이스 사용
- **UI만 차별화**: 기능은 동일, 화면 구성만 영업팀에 최적화
- **기존 코드 재사용**: 관리팀 기능 참조하여 개발

## 3. 기능 상세

### 3.1 팀 선택 화면

| 항목 | 내용 |
|------|------|
| 경로 | `/mobile` (기존 경로 유지) |
| 구성 | 2개 카드: 영업팀, 관리팀 |
| 관리팀 | 현재 `/mobile` 화면으로 이동 |
| 영업팀 | 새 영업팀 홈으로 이동 |
| 접속 기억 | ❌ (매번 팀 선택) |

---

### 3.2 입출고 등록 (드롭다운 3개 옵션)

#### 3.2.1 입고 처리
| 항목 | 내용 |
|------|------|
| 목록 표시 | 현재 **출고 상태**인 기구 목록 |
| 정렬 | 최신 출고순 |
| 버튼 | 각 항목에 `[입고처리]` 버튼 |
| 사진 처리 | 삭제 ❌ → **이전 출고 사진** 탭에 보관 |
| 자동 갱신 | 입고 시 현황표 즉시 반영 |

#### 3.2.2 출고 처리
| 항목 | 내용 |
|------|------|
| 목록 표시 | 현재 **입고 상태**인 기구 목록 |
| 선택 시 팝업 | 병원명, 담당자, 사진 첨부 |
| 병원명 | 드롭다운 (기존 목록) + 신규 입력 → 자동 추가 |
| 담당자 | 드롭다운 (기존 목록) + 신규 입력 → 자동 추가 |
| 사진 | **필수**, **무제한** 첨부 |
| 날짜/시간 | **자동 저장** |

#### 3.2.3 신규 기구 등록
| 항목 | 내용 |
|------|------|
| 기구명 | 텍스트 입력 |
| 기구 번호 | **수동 입력** (예: #1, #2) |
| 사진 등록 | 필수 - **카메라 촬영** 또는 **앨범 선택** (기존 관리팀 코드 활용) |
| 추가 정보 | 불필요 |

---

### 3.3 입출고 현황 (Dashboard Grid)

| 항목 | 내용 |
|------|------|
| 레이아웃 | **3열 그리드** (모바일 최적화) |
| 행 구성 | 동일 기구명이 가로로 나열 |
| 예시 | `지니어스#1` \| `지니어스#2` \| `지니어스#3` |
| 4개 이상 시 | 3개씩 끊어서 다음 행으로 |
| 빈 칸 | 기구 1~2개면 나머지 칸 비움 |
| 상태 표시 | 배지: `입고` (녹색) / `출고` (빨간색) |
| 정렬 | 최초: 기구 수 많은 순 → 이후: 최신 갱신순 |
| 자동 갱신 | 입출고 등록 시 즉시 반영 |
| 기록 유지 | 입고 시 최근 **출고 장소 3건** 히스토리 보관 (어느 병원에 있었는지) |

#### 입고/출고 상태 판별 기준
| 위치 | 상태 |
|------|------|
| **부산사무실** | `입고` (녹색 배지) |
| **그 외 모든 장소** | `출고` (빨간색 배지) |

## 4. 데이터 구조 (기존 DB 활용)

### 4.1 기존 테이블 활용
- `lending_items`: 입출고 기록
- `hospitals`: 병원 목록
- `users` 또는 `personnel`: 담당자 목록
- `lending_item_photos`: 출고 사진

### 4.2 추가/수정 필요 사항
| 테이블 | 변경 내용 |
|--------|-----------|
| `lending_item_photos` | `is_archived` 컬럼 추가 (이전 사진 보관용) |
| 또는 새 테이블 | `archived_photos` (출고→입고 시 사진 이관) |

## 7. 검증 계획

| 항목 | 방법 |
|------|------|
| 팀 선택 | 영업팀/관리팀 각각 올바른 화면 이동 확인 |
| 입고 처리 | 출고→입고 전환 + 사진 아카이브 확인 |
| 출고 처리 | 사진 필수 검증 + 병원/담당자 저장 |
| 현황판 | 그리드 레이아웃 + 자동 갱신 확인 |
| 데이터 동기화 | 영업팀 변경 → 관리팀 반영 확인 |
